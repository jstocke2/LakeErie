# LakeErie

Calculates the number of gallons of water in Lake Erie.

## Description

This Python program calculates an estimate of the total volume of water in Lake Erie in gallons. It uses geographical data and measurements to compute this large-scale environmental metric.

## Features

- Lake Erie volume calculation
- Conversion to gallons
- Environmental data processing
- Educational demonstration

## Technology Stack

- **Language**: Python 3.x

## Prerequisites

- Python 3.x

## Usage

```bash
python lake_erie.py
```

## How It Works

The program:
1. Loads or calculates Lake Erie dimensions
2. Computes volume based on area and average depth
3. Converts cubic measurements to gallons
4. Displays the result

## Lake Erie Facts

- Fourth largest Great Lake by surface area
- Average depth: ~62 feet
- Surface area: ~9,910 square miles
- Volume: Approximately 116 cubic miles

## Output

The program outputs the estimated number of gallons of water in Lake Erie.

## Example Output

```
Estimated gallons of water in Lake Erie: [calculated amount]
```
